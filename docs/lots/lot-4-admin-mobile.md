4. **Écran Aujourd'hui** : actions principales (démarrer, terminer, photo) sans défilement.
5. **Planning unifié** : lisibilité des pastilles de couleur, légende repliable.
6. **Total mensuel des km administratifs** dans l'onglet Charges.
