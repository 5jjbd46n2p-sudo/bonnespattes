# Lot 3 : portail client

Objectif : un écran d'accueil qui répond à « comment va mon animal ? » avant tout.

## Tâches
1. **Accueil `app/portal/page.js`** centré sur « les nouvelles de [animal] » : dernier compte rendu, photos en grand avec visionneuse, prochaine visite.
2. **Factures à régler en tête**, avec le moyen de paiement (IBAN, référence) visible sans cliquer.
3. **Contrat** : résumé en quelques lignes avant le texte complet, état (à signer, signé, scellé le [date]) selon le lot 0.
4. **Historique** : regroupement par mois, compte rendus lisibles.
5. **Navigation** (`PortalNav`) : trois entrées claires (Nouvelles, Factures, Mon compte).
6. **Vouvoiement** et ton cohérents ; messages d'erreur utiles.

## Vérification
Parcours client complet sur mobile : connexion, lecture d'un compte rendu, paiement d'une facture, signature du contrat.

## Dépendances
Lots 0 (phase B, sceau des contrats) et 1.
